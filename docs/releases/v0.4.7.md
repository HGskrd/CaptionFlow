Smaller macOS installers: Apple Silicon keeps every supported speech model while dropping unused PyTorch/LLVM dependencies, development files and tests. Disk images use stronger compression.

- **Windows:** run `CaptionFlow-Setup.exe`.
- **macOS:** open the matching DMG and drag to Applications. Apple Silicon requires macOS 26+; Intel requires macOS 14+.
- **Arch/EndeavourOS:** use `PKGBUILD` with `makepkg -si`, or install the pacman package. Launch `captionflow`.

Windows signing is pending. Mac first launch may require **Privacy & Security → Open Anyway**. Linux remains a preview; updates install manually.
