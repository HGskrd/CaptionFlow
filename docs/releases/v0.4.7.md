Smaller Mac installers and two Windows download options.

- **Windows normal:** `CaptionFlow-Setup.exe` is small and requires internet during installation.
- **Windows all-in-one:** `CaptionFlow-Setup-All-in-One.exe` includes all app code and runtimes. Model weights are separate for both.
- **macOS:** open the matching DMG and drag to Applications. Apple Silicon requires macOS 26+; Intel requires macOS 14+.
- **Arch/EndeavourOS:** use `PKGBUILD` with `makepkg -si` or install the pacman package. Launch `captionflow`.

Windows signing is pending. Mac may require **Privacy & Security → Open Anyway**. In-app rollout is pending; use these downloads.
